# CT-005 读写文件或联网出现权限错误

依据：官方权限说明整理，本仓库不将任意拒绝访问归为同一种故障。核对日期：2026-10-21。

## 问题

命令报 Permission denied、Access is denied 或文件系统、网络受限。目标可能位于当前工作区之外。

## 原因

Windows 沙箱按有效的文件系统及网络权限约束命令和子进程；审批策略决定能否请求更多访问。操作系统文件权限、文件锁、组织策略也可能造成相似错误。[官方 Windows 沙箱说明](https://learn.chatgpt.com/docs/windows/windows-sandbox)

## 解决方案

先核对失败的具体操作、绝对目标路径及当前权限范围。工作区外的必要写入应通过当前环境支持的权限申请方式取得最小所需访问；网络问题单独检查网络授权。文件锁问题先正常关闭占用程序；组织策略限制交由对应管理员处理。

不要将错误直接当成需要全盘权限或关闭沙箱的理由，也不要在反复拒绝后绕过同一限制。

## 验收

只对明确授权的目标执行本次必要操作，读回结果核对。确认其他路径、网络访问及审批偏好未被额外扩大。

## 回退与限制

撤销不再需要的额外授权，恢复本次有意改动的配置。具体权限接口、临时授权有效期和管理策略依运行环境而异，不提供一个通用“解除限制”命令。
